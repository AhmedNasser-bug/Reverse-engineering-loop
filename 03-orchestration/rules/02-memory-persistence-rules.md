# Rule 02: Honcho Memory Persistence Protocol

## 1. Zero Context Amnesia
- No loop iteration shall execute in isolation without accessing persistent memory.
- Worker agents must pull historical context from `03-orchestration/honcho/honcho_client.py` prior to task dispatch.

## 2. Dialectic Integrity
- All user agreements, preference adjustments, and invariant approvals must be logged into Honcho session memory.
- The dialectic state represents the single source of truth for agent behavior and alignment.

## 3. Persistent Knowledge Retention
- All hypotheses, falsifications, and reverse-engineered learnings generated by REA or the Evaluation Agent must be persisted to the session's JSONL learnings store.
- If the harness process restarts, it must seamlessly resume from the saved Honcho session state.
